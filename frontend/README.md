# Rapid Radiology frontend

React + TypeScript + Vite single-page app. See the [root README](../README.md) for what the project is and [docs/development.md](../docs/development.md) for setup.

| Command                                   | What it does                                                |
| ----------------------------------------- | ----------------------------------------------------------- |
| `npm run dev`                             | Dev server against a real backend (needs `frontend/.env`)   |
| `npm run dev:demo`                        | Dev server in [demo mode](../docs/demo-mode.md): no backend |
| `npm run build`                           | Type-check and production build                             |
| `npm run build:demo`                      | Production build in demo mode                               |
| `npm run screenshots`                     | Regenerate the README images and GIF in `docs/images/`      |
| `npm run lint`                            | ESLint                                                      |
| `npm run format` / `npm run format:check` | Prettier                                                    |
